# Peaky Notes

Учебный репозиторий бесплатного курса GitHub Peaky Minds.

## План

1. Создать репозиторий.
2. Прочитать историю.
3. Предложить изменение через Pull Request.

## Как повторить

Создайте собственный репозиторий. Не отправляйте учебные изменения в чужие проекты.

Материалы курса: https://stepik.org/course/302401
